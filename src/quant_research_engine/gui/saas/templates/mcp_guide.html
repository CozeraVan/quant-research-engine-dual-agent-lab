MCP 使用说明

让支持 MCP 的 AI 客户端调用 A 股回测能力：校验策略、提交小样本任务、跟踪进度、读取报告并保存到本地。

接入准备 客户端配置 执行回测 工具清单 本地导出 权限与边界

1. 接入准备

登录后进入个人中心的「MCP 接入」，创建独立 Agent token。可设置有效天数，以及是否只允许夜间执行。

创建 Agent token

令牌明文只在创建成功时显示一次。请立即保存；丢失后不能找回，只能吊销并重新创建。

MCP 地址https://aguhuice.com/mcp
认证方式Authorization: Bearer <你的 Agent token>
传输协议Streamable HTTP

2. 客户端配置

在本机使用 Kimi Code 等 CLI 时，可直接通过手机号和短信验证码登录，不必进入网页复制 token：

qre-mcp-login

登录命令会先发送短信，再要求输入验证码。成功后会自动创建 Agent token，并保存到本机权限受限的配置文件；后续 MCP 与本地导出命令自动读取。使用 qre-mcp-login --logout 可吊销 token 并删除本机凭证。

如果需要手动配置 Remote MCP 客户端，则使用下面的地址，并把请求头中的占位符替换为你自己的令牌。不要把真实令牌提交到代码仓库或分享给他人。

{
  "mcpServers": {
    "qre-backtest": {
      "url": "https://aguhuice.com/mcp",
      "headers": {
        "Authorization": "Bearer <你的 Agent token>"
      }
    }
  }
}

不同客户端的配置字段可能略有差异；核心是 Remote MCP URL 与 Authorization 请求头。

3. 执行一次小样本回测

顺序操作结果
1读取策略 Schema，准备 YAML、股票范围和日期区间得到可校验的策略定义
2调用策略校验返回因子、参数错误和成本估计，不执行任务
3创建研究会话并设置计算预算返回 research_run_id
4提交单个 screen 回测，提供唯一幂等键立即返回 sweep_id，不等待回测结束
5轮询状态，完成后读取 job 结果得到摘要、指标和产物清单

首次使用建议选择 2～5 只股票、近 6 个月。小样本用于验证流程，不构成策略有效性结论。

4. 工具清单

工具用途
get_capabilities查看规模档、预计耗时和容量限制
get_strategy_schema读取策略 YAML 的 JSON Schema
validate_strategy校验策略与参数，不执行、不建单
create_research_run创建研究边界和计算预算
submit_backtest提交单个 screen 异步回测
get_backtest_status查询 sweep 与子 job 状态
get_backtest_aggregate读取数值聚合，不生成投资解读
get_backtest_result读取本人已完成任务摘要
get_backtest_chart_data按需读取收益、回撤等图表数据

5. 把结果保存到本地电脑

回测结果仍可在网页查看。需要离线分析或视频制作时，可让本机 Agent 调用以下命令，把核心结果包保存到当前电脑：

export QRE_AGENT_TOKEN='<你的 Agent token>'
export QRE_API_BASE_URL='https://aguhuice.com'
uv run qre-mcp-export 360 --output ./qre-results

将命令中的 360 换成实际 job_id。默认目录为 qre-results/job_<id>/，包含参数结果、核心指标、收益与回撤、交易汇总和 HTML 报告。

导出器逐文件校验 SHA-256，失败会清理半成品，不覆盖已有目录。默认不包含逐股目录、图片和 Excel。远程服务器不会直接获得你电脑的磁盘写权限，保存动作由本机 Agent 完成。

6. 权限与边界

任务归属同一账号的有效 token 可读取该账号历史结果；其他账号不可见。
容量限制每个令牌仍受每日提交、在飞任务、请求频率和研究预算约束。
当前范围只开放单配置 screen 小样本，不开放全市场 confirm。
云端存储本地导出不改变现有云端保留策略，也不会自动删除云端结果。
令牌管理不再使用时请及时吊销；吊销后立即失效。
研究声明所有结果均为历史模拟，仅供研究使用，不构成投资建议。
