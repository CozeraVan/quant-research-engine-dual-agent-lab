### 计费原则

- 免费动作：能力/Schema、校验、状态轮询、已有结果摘要读取、本地导出。
- 计费动作：新回测，按标的数、实际交易日跨度、配置数和报告深度消耗积分。
- 幂等重复提交不重复扣分；失败/取消按实际阶段自动返还，具体规则在支付前实现并公示。
- 月度额度按订阅周期重置；是否允许结转、加量包和到期规则待定价时裁定，不默认永久有效。
- 同一账号的网页与 MCP 共用积分余额、用量流水和 9090 同源展示。
- 不在本文件预设价格或积分汇率；先用真实 worker 成本与失败率校准。

## 个人主体收费边界

不能简单回答“个人可以直接在 aguhuice.com 收费”。需逐条核实：

- 当前备案主体、网站内容与付费服务是否一致；经营性互联网信息服务是否需经营许可/变更，向备案与通信管理渠道确认。
- 微信支付/支付宝等收单机构是否接受当前主体及该 SaaS 类目；不要依赖个人转账代替正式订单。
- 税务登记、收入申报、发票能力、消费者权益、退款与自动续费规则。
- 金融研究工具不得承诺收益，不把回测报告包装成荐股或代客理财；服务协议明确历史模拟边界。
- 若当前主体条件不满足，等公司/个体工商户主体与支付类目就绪后再开真实收费，不通过私人收款绕过。
