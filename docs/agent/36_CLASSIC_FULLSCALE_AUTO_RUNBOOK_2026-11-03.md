## 3. 自动执行规则

1. 主 Agent 按编号串行提交，一次只执行一个全期全量任务；完成结果与产物审计后才进入下一项。
2. 失败立即记录错误分类并派子代理：
   - 缺因子/因子覆盖不足：核查别名、表列与历史覆盖；需要补算时交上游因子任务，先小范围回补和 SQL 对账，不改 `stock_daily`。
   - NL/向导/YAML 语义或编译问题：复用统一语义与因子注册表修复，不伪造成功。
   - 引擎/统计/回传/前端 bug：先红灯复现，最小修复，定向测试 + 全量回归，按部署纪律上线。
3. 修复后必须先重跑该策略的小样本；通过后从**当前编号**恢复全量，不跳到下一项。
4. 同一任务不盲目自动重试；只有根因已修复且小样本通过才重跑。保留每次失败证据，不覆盖历史。
5. 子代理不自行 commit/push/部署/重启；主 Agent 负责验收、ECS 部署与 worker 安全重启。代码提交仍按项目 Git 审批纪律处理。
6. 全量收益只是当前策略与口径的结果，不作为投资有效性结论；18 个文字穿越与 YAML 状态差异继续显式保留，不静默改写成另一种策略。
