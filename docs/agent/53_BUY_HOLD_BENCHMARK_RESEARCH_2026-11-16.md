# 53. 买入持有基准的外部软件口径调研（2026-11-16）

## 外部实现

- VectorBT `Portfolio.from_holding`：首个价格投入现金，最后价格估值；官方例子明确收取入场费，但不对假想平仓收取末次费用。来源：https://vectorbt.dev/getting-started/usage/
- Backtrader `Benchmark`：跟踪指定参考资产的完整区间收益；默认从策略满足最小周期后开始，`_doprenext=True` 才从数据起点记录；`firstopen=False` 时首个比较点从0开始。来源：https://www.backtrader.com/docu/observers-reference/
- QuantConnect/LEAN：基准是一只指定证券的买入持有序列；美股历史价格可将拆股和分红调整到价格中。来源：https://www.quantconnect.com/docs/v2/writing-algorithms/securities/asset-classes/us-equity/requesting-data
- Zipline：以独立基准收益序列计算日收益/累计收益与波动，不是按策略交易股重新生成基准。来源：https://zipline.ml4trading.io/appendix.html

## 对本项目的结论

1. 当前“每股首开盘→末收盘、再对全宇宙等权平均”的含义是：每只股票分配相同初始资金、之后不再平衡的买入持有组合。它不是指数收益，也不应命名为指数基准。
2. 复权因子口径近似“分红再投入的总收益”，不是现金分红闲置账户；需要明确标注。不计交易成本是毛基准；VectorBT 的入场费处理说明各软件在费用上也存在合同差异。
3. 对全市场策略应同时展示：等权持有组合收益、收益中位数、有效股票数，以及一个固定指数/全收益指数。均值会被极端赢家显著拉高。
4. 相同宇宙、区间、行情快照下基准固定；新股使用上市后有效边界，无交易股票也纳入。退市股仅取最后收盘是“最后可得价估值”，不自动等于真实清算回收。
5. 历史股票池必须包含当时存在但后来退市的股票，避免幸存者偏差；无有效价格边界时剔除并计数，不填0。

本文件为调研记录，不改变刚提交的实现，不启动回测。
