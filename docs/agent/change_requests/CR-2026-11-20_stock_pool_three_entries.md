# CR-2026-11-20 股票池三入口

## 用户要求

股票池与QRE回测一致，提供自然语言、快速向导、高级YAML三个入口。

## 统一语义

- 三入口最终都形成同一StrategySpec：`data.factor_fields/market_fields + signal.entry`；股票池只计算最新截面entry布尔值，不执行exit、交易、资金或收益。
- 自然语言复用现有`/api/saas/nl/compile`，编译成功后提交最终YAML；向导保留当前单条件构造器并生成同义YAML/条件；高级YAML直接编辑完整策略。
- 简单向导继续走单SQL快路径；NL/YAML由worker按引用字段读取最近400个自然日面板，按股票分组使用既有安全表达式求值器，避免shift跨股票。
- 输出沿用名单合同；表达式模式不伪造“左右值”，只展示代码/名称/收盘。保留最近日期、候选数、命中数、400日回看声明。
- 复用既有YAML安全闸、因子限制、NL配额、任务归属与幂等。首版仍不扩展保存池/自动日更。

## 验证

TDD覆盖YAML示例与单SQL对账、AND/shift表达式、缺字段/不安全YAML拒绝、worker策略YAML分发、API非法YAML、三入口页面与编译链标记。部署后实测向导和YAML示例；NL只做编译提交链验证，不跑回测。
