## 首版范围

1. 新增独立 `strategy_type: chanlun_structure`，不伪装成普通 pandas 表达式。
2. OHLC 经确定性包含处理、分型、笔、线段和固定三笔中枢算法生成结构；MACD histogram、ATR 仍从输入因子列读取，不在引擎重算。
3. 每个交易日只使用当日及此前数据。记录结构端点与确认时点，信号只在确认后产生，默认下一交易日开盘成交。
4. 风险等级 0–9 仅 B1，10–19 B1+B2，20–30 B1+B2+B3；首版 A 股只做多，S1/S2/S3 作为退出研究字段，不建立空仓。
5. 输出统一 `entry_signal/exit_signal`，附 `signal_type/stop_price/take_profit_price` 等诊断列。首版组合执行先复用固定百分比风控；动态结构价格止损和 2R 止盈作为显式扩展接入，不得静默退化成固定百分比。
6. 不做同股滚仓、不做空、不模拟 tick 级移动止损、不做周五强平；日亏闸门留待组合级后续任务。

## 因果与验收

- 分型需右侧有效 K 确认；笔需后续反向分型确认。禁止把信号回填到历史极值日交易。
- 合并 K 保留首根 open、按方向合并 high/low、末根 close，并保留原始起止索引。
- 同向分型保留更极端者；反向分型间距不足时保留最近有效结构并明确处理规则。
- 中枢 ZG/ZD 由初始三笔固定，延伸不收紧；完全脱离后封闭。
- 背驰只累加同号 MACD 柱，要求面积比 <0.85 且价格创新极值。
- 合成测试覆盖每层、风险等级、确认滞后、无未来函数、NaN、短序列和重复运行确定性。
- 若获得原始 5000 根样本，再对账 2679/1480/298/36/45/392；没有样本前不得声称已复现这些数量。
- 代码完成后只跑定向/轻量测试；真实回测先 3–5 股短窗口，避开正在运行的 CF 重负载队列，不直接全量。
