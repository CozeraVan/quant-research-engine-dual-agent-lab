# CR-2026-11-17：超额收益统一为上证指数口径，移除持有至到期统计

## 用户决定

不再统计股票/股票池的持有至到期（买入持有）收益。所有“超额收益”统一指策略收益减同期上证指数收益；不保留持有基准回退。

## 权威口径

- 固定基准：`reference.index_daily` 的 `000001.SH`（上证指数）。
- 策略级：`excess_return_vs_benchmark = strategy_total_return - benchmark_return`。
- 个股级：该股策略净值实际首末交易日对应的上证指数首末收盘计算区间收益，再与该股策略收益相减。
- 曲线缩放区间：同一可见窗口内策略累计收益减上证指数累计收益。
- 缺少上证指数或策略收益时，超额为 `null`，不得以买入持有替代。
- 总收益、交易、费用、回撤等其他指标不变；仅移除持有基准统计/曲线/文案及其派生超额。
- 多指数曲线仍可展示，但“超额收益”固定使用上证指数，不随当前选中的其他指数改变。

## 范围

1. 引擎与报告：停止生成 `buy_hold_return`、`excess_return_vs_buy_hold`、`buy_hold_equity` 和持有口径 IR；新增基准代码/名称/收益及 `excess_return_vs_benchmark`。
2. 晋升、日更、策略适配/聚类输入、MCP/API 的超额字段改用新口径。
3. 8081 与 SaaS 的策略、个股、历史记录、经典列表、帮助页移除持有收益卡/曲线和旧超额文案。
4. 历史生产结果备份后批量迁移：删除持有曲线和旧字段，按已存上证指数曲线重算新超额；缺基准者留空，不编数。
5. 不改变交易结果，不重跑全量回测，不改行情表。

## 验收

- 新口径公式、缺基准 null、无持有回退均有回归测试。
- 策略与个股页面无“买入持有/持有至到期/持有不动”统计项，曲线只有策略、指数和回撤。
- 同任务的总收益与交易数不变，超额等于总收益减上证指数收益。
- 相关测试、浏览器桌面/移动端、静态图与重播、ECS 生产核验通过。
