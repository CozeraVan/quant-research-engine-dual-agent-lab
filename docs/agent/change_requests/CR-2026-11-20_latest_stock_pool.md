# CR-2026-11-20 最新截面股票池

## 用户目标

按最新交易数据筛选股票池，例如 `EMA5 > EMA200`，返回所有符合条件的A股。

## 首版设计

- 单条件：左侧选择行情/因子字段，操作符 `> >= < <= = !=`，右侧选择另一字段或输入有限数值。示例默认同表 `stock_daily_overlap_typical_price.ema_5 > ema_200`。
- 日期为 `public.stock_daily.max(trade_date)`；只纳入该日有行情且两侧比较值均非空的股票，不回填旧因子、不计算技术指标、不产生交易信号或收益结论。
- 返回交易日、候选总数、命中数、代码、名称、收盘及左右值。结果属当次用户私有任务，不进入回测历史。
- ECS不直连行情库：新增轻量 `stock_pool` 队列任务，由本机worker只读查询并通过既有结果回传；页面异步轮询。
- 仅登录用户可提交，沿用既有鉴权、幂等、任务隔离；首版不做多条件、板块过滤、保存股票池或自动日更，避免扩大范围。
- 所有表名/列名采用严格标识符白名单，操作符枚举，数值参数化；禁止任意SQL/表达式执行。

## 验证

TDD覆盖示例条件、因子对数值、空值排除、非法表列/操作符/NaN拒绝、真实库最新截面独立SQL对账、API鉴权/归属/幂等、worker无YAML分发、页面与回归。只执行轻量SELECT，不启动回测。
