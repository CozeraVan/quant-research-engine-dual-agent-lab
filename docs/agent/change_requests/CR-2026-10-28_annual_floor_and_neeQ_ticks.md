# CR-2026-10-28 持仓期年化下限修复 + 新三板坏 tick 数据体检

## 背景

用户报告 job#66 的 920556 个股回测详情「持仓期年化收益」显示
**5051142288902.57%**，且该股交易集中在区间前段，怀疑新三板/旧三板数据导致异常。

## 定位

### 1. 主因：年化外推失真（已修）

920556.BJ（雅达股份）实测数据：

| 项 | 值 |
| --- | --- |
| 交易笔数 | 3（全部在 2015-03-19 ~ 2015-05-07） |
| 交易日数 | 2295（2014-01-24 ~ 2026-10-12） |
| 持仓暴露度 | **1.05%**（约 24 / 2295 交易日） |
| 区间策略收益 | 945.61% |

原公式 `(1+区间收益)^(252/持仓交易日)−1`：
`(1+9.456117)^(252/24)−1 = 5.05e10` → 页面显示 5051142288902.57%。

`持仓期年化` 的本意是「在场期间的单位时间收益率」，但**持仓不足一个完整年度时
这是外推**：指数 252/持仓日 会把收益放大到失真。上一轮修复（a1516f0）只把分母
从「equity 条目数」换成「实际持仓交易日」，对本例反而让指数更大（条目数更多 →
指数更小；换成 24 天后指数从 ~3 涨到 ~10.5）。

### 2. 次因：新三板-era 坏 tick（已体检，未修）

`stock_daily` 中同一根 K 线内 `low < 0.2 × close` 的异常行：

- **全市场仅 79 行 / 26 只股票**（占 5860 只的 0.44%），集中在 2015(51)、
  2016(19)、2017(8)、2020(1)。
- **26 只全部是 `920xxx.BJ`**（北交所，2015 年前后在新三板交易），与用户判断一致。
- 920556.BJ 自身有 9 行，如 `2015-03-16 low=0.01 / close=19.1`、
  `2015-06-04 open=0.01 / close=1.08`。

影响面：只污染 `low`（及个别 `open`）。收盘价类信号（如 job#66 的 EMA 策略）
不受影响；intrabar 止损、ATR/波动率类因子在这些日期会失真。**未修改任何数据**，
处置方式待用户决定（见「待决」）。

## 修复：年化下限

`lab-ui.js` 新增单点实现，SaaS job/symbol 两个区间卡共用：

```js
LabUI.ANNUAL_MIN_TRADING_DAYS = 252;   // 一个完整年度
LabUI.holdingAnnualized(sRet, heldDays)   // 不足 252 → null；负基数/非有限 → null
LabUI.holdingAnnualNote(heldDays)         // 不成立时的原因说明
```

- `holdingAnnualized`：`sRet` 缺失/NaN/Inf → null；`1+sRet <= 0` → null；
  `heldDays < 252` → null；否则 `(1+sRet)^(252/heldDays)−1`，结果非有限 → null。
- `holdingAnnualNote`：`heldDays < 252` 时返回
  「；持仓期不足一个完整年度（N < 252 交易日），年化不成立」，否则空串。
- `symbol.html` / `job.html` 的 `exposureCards()` 改为调用 helper，并删掉模板内
  自带的 `Math.pow(1 + sRet, 252 / heldDays)` 公式（收敛到单点，防再次漂移）。
- tooltip 补明年化下限说明，用户看到「—」时悬停可知原因。
