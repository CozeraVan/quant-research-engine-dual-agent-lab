# CR-2026-10-04 回测重播（策略级 + K线级）

状态：已获用户批准（2026-10-04 两轮可行性评估对齐）
来源：用户参照 MT5/TradingView bar-replay 提出；评估结论——数据全现成、零引擎改动、
前端为主，差异化价值高。

## 范围与顺序

- **切片1（优先）**：策略级重播（job.html 回测详情页）+ 可复用「重播引擎组件」
- **切片2**：K线级重播（symbol.html 个股详情页，复用切片1组件）
- 明确不做：多股并行组合回放、重播中改参、云端任何新接口/引擎改动

## 核心设计

### 重播引擎组件（新前端模块，saas 与 lab 共享目录）

- 输入：时间轴（交易日序列）+ 逐帧数据提供者 + 事件列表（按日索引）
- 控制条：播放/暂停、单步、速度档（1x/2x/5x/10x=每帧追加 1/2/5/10 根 K）、
  起始日选择（复用日历组件）、可拖拽进度条、**「空仓快进」按钮**
  （跳到下一个有事件/持仓变化的交易日——MT5 经验：空仓期无意义播放）
- 渲染纪律：全量数据内存持有，每帧只把 [0, cursor] 截断喂 ECharts；
  未来数据天然不可见（防偷看与 TV 同口径）；setOption 节流（帧预算 ~16ms）
- 移动端：控制条折行、图表自适应（12 号文档 §10 断点）

### 切片1：策略级重播（job.html）

数据（全部已在页面/产物中）：
- 策略净值/基准/回撤逐日序列 → 逐日生长
- round trips + orders → 事件流：入场/出场弹入（代码+价格+盈亏标签）；
  **全市场同日几十只触发时聚合显示「当日入场 N 只」点击展开**
- 逐日持仓掩码（暴露度卡既有展开逻辑复用）→ 当前持仓数/暴露度
- 指标面板逐帧重算（前端对截断序列 O(n) 计算）：累计收益、最大回撤
  （动态峰值刷新视觉提示）、夏普、胜率、盈亏比、持仓数、暴露度

### 切片2：K线级重播（symbol.html）

数据：OHLCV 全区间序列 + 预计算因子 + orders 买卖点
- K线/因子副图/成交量逐日推进；order.date <= cursor 的买卖点弹入（动效）
- 侧边信息卡：当前日 OHLC、因子值、浮动盈亏（持仓中按当前帧收盘价算 unrealized）
- 重播窗口限制（全期约 3800 根有渲染压力）：默认近 2 年，可改起始日；
  实测后定是否用 appendData 增量渲染放开限制

## 时序口径（两切片共同红线）

T 日收盘出信号、T+1 开盘成交：信号标记与成交点必须隔一个交易日出现，
不得神化策略时序。页面保留既有免责声明。

## 测试与验证

- 组件级：截断逻辑/事件索引/空仓快进跳转正确性（JS 侧可用 node 或页面探针断言）

  指标数值与静态页终值一致（播放到最后一帧 = 现有报告数字，强一致性校验），
  零横滚零 JS 报错
- 现有 saas 测试全绿（基线 235）；模板断言按需更新

## 风险

- 全期渲染压力 → 窗口限制 + 节流，实测兜底
- 同日信号洪峰 → 聚合显示
- 事件流与净值序列日期对齐（交易日历差异）→ 以净值序列交易日为主轴，
  事件按日归箱
