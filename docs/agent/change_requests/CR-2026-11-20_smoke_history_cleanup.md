# CR-2026-11-20 冒烟任务隐藏与文件清理

## 用户要求

每个正式任务前的冒烟测试不显示在回测历史；测试结束后删除冒烟测试生成的源文件/产物。

## 边界

- 隐藏指用户回测历史和本地8081记录，管理员工具/任务轮询仍可读取必要状态。
- 删除冒烟 run 目录、独立 output_dir、worker 沙箱及云端 `job_<id>` 上传产物；不删沙箱策略 YAML、策略库记录、云端 jobs/results 摘要、sidecar 指标，也不影响关联正式任务。
- 本地在 sidecar/风险收尾后清理；worker 在云端终态上报后清理；云端在结果接收完成或失败/取消终态后清理。上报失败（unknown）保留本地产物以便恢复。
- 仅 `precheck=true` 或 `purpose=smoke` 的终态 run 可清理；路径必须是受管 run 目录、其 artifacts 子树或以 run_id 命名的独立输出目录，禁止任意 output_dir 删除。

## 验证

TDD 覆盖历史隐藏、终态清理、策略/sidecar保留、正式run拒绝清理、路径越界拒绝、worker上报失败保留、云端文件终态清理。使用临时目录，不运行真实冒烟/全量任务。
