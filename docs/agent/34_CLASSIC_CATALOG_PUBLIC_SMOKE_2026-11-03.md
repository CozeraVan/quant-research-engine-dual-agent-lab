## 1. 目标与边界

1. 为全部策略整理可读说明：策略名、类别、指标及含义、文字入场/出场、实际 YAML 入场/出场、持仓与风控、因子表列。
2. 将全部策略按固定随机种子、按类别分层分配到 aguhuice.com 三入口（自然语言 / 自选因子 / 策略代码），先测编译与提交可行性，再记录入口特有限制。
3. 全部策略使用**同一批随机 100 只 A 股、同一两年区间、同一执行与费用参数**做 batch 冒烟，检查最新引擎统计路径、产物与异常。
4. 汇总缺因子、编译失败、执行失败、零信号、统计异常与前端异常；缺因子只形成需求清单，不在本任务自动补算。
5. 本冒烟只验证管线，不把两年 100 股收益当作策略有效性结论；全部通过后才由用户另行授权全期全量。

## 2. 统一口径

- 回测模式：`batch`；初始资金、费用、滑点、T+1、进出场执行等使用公网当前默认高级参数，落盘后记录真实值，不在策略间改动。
- 区间：两年，暂取 `2024-11-01 ~ 2026-10-30`（以当前数据库最新完整日线 2026-10-30 为终点；执行前复核）。
- 股票池：从符合当前宇宙规则的候选中按固定 seed 抽取 100 只；所有策略复用同一代码清单，清单与 seed 持久化。北交所三板残留继续按现行宇宙闸排除。
- 调度：串行提交/执行，不与 P0-9 或其他重负载测试并行，不做压力测试；每个策略使用幂等键，失败不自动全量重试。
- 原始策略 YAML 不在本任务擅自“修正”。文字说明与实际表达式不一致（例如文字写金叉、YAML 为持续 `>`）必须单独标记；NL 编译结果与原 YAML 语义不同也单独标记，不能混入同一收益对比。

### S3 118 策略统一冒烟
