# 回测参数口径与单位提示设计

日期：2026-10-25
状态：用户确认由 Kimi 实施，采用 label 悬停/点击说明，不改默认值和回测逻辑。

## 范围

新建策略页的回测参数和高级参数。复用 `LabUI.helpTips()` 与 `[data-tip]`，桌面悬停、键盘聚焦、移动点击均可查看，不新增图标或可见灰色备注。

## 内容

- 基础参数：策略 ID、回测区间、标的范围、板块/概念、随机数量、指定代码。
- 资金：共享资金为多标的共用总资金；批量为每只股票独立使用初始资金。初始资金单位为元。
- 持仓：最大持仓股票数 0=不限；最大持仓天数 0/留空=不限，当前默认 20 天不改。
- 价格：信号后的下一交易日开盘价、收盘价或 VWAP。
- 风险：止损/止盈为相对入场价的小数比例，移动止损为相对持仓期间最高价的小数回撤比例；0.08=8%，留空/0=不启用。
- 费用：佣金率、印花税、滑点均用小数；0.0003=0.03%，最低佣金单位元。
- 回测区间按实际起止日期执行，全期入口从 2010 年起；股票代码无需交易所后缀。

## 验收

- 每个参数 label 均有准确 data-tip，移动可点击，说明不被输入框遮挡。
- 重点实测模式、初始资金、持仓、价格、风险比例、费用。
- 不改变参数值、YAML 合并、策略编译或回测行为。
- 真实 Chromium 桌面 1280/移动 375，相关测试及全量回归通过。
