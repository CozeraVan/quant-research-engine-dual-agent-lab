# 自选因子三栏弹窗选择器设计

日期：2026-10-25
状态：用户已确认三栏弹窗＋搜索；Step 5 实施，先部署 ECS 验收，不 commit、不 push。

## 目标

自选因子入口不再在一行内堆叠三级下拉。每个因子位置以选择按钮显示当前值，点击后打开三级联动弹窗，改善大量因子的浏览与定位效率。

## 交互

- 按钮显示当前“大类 / 子类 / 因子”；未选时显示“选择因子”。
- 弹窗包含大类、子类、因子三栏和名称/字段搜索；点击父级仅更新下级，点击最终因子后回填并关闭。
- 搜索展示匹配因子及其完整层级，选中后同步三栏。
- 支持关闭按钮、Esc、点击遮罩和键盘操作；弹窗打开后焦点进入搜索，关闭后焦点回到原按钮。
- 桌面居中紧凑弹窗，移动端接近全宽并限制高度，内容内部滚动，不产生页面横向溢出。
- 风格复用现有 modal、按钮、表单和紫色主题，不新增依赖或色相。

## 数据契约

保留 `.wz-left`、`.wz-rfield` 的值和 change 语义。可用隐藏 select 作为唯一数据字段，按钮仅负责呈现和打开弹窗；YAML、`usedFactors()`、`readGroup()`、固定值切换、条件快照、策略还原、price basis 归一逻辑均不改。

弹窗直接复用 `FACTOR_OPTIONS`、`factorGroups()`、`factorSubs()` 和现有目录加载结果，不新增 API。目录未加载或加载失败继续沿用现有状态与错误提示。

## 实施范围

仅 `new.html`、共享主题 CSS（如确有需要）、相关前端测试和长期文档。自然语言、策略代码、回测引擎、数据库和其他页面不改。

## 验收

- 左右因子均能通过弹窗完成三级选择，按钮和 YAML 值一致。
- 搜索、清空搜索、父子级切换、连续打开关闭、Esc/遮罩、焦点返回正常。
- 固定值切换、条件增删、AND/OR、策略快照还原和预览刷新不回归。
- 真实 Chromium 桌面 1280px 与移动 375px 验证，无 JS error、无横向溢出。
