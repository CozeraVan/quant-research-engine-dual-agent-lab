# SaaS 说明文案精简与统一悬停说明设计

日期：2026-10-25
状态：用户已确认统一组件方向，并批准设计文档本地提交；不 push、不部署。

## 目标

减少全站重复灰色备注，同时不牺牲回测口径、操作约束与风险信息的可理解性。模块说明集中到标题旁的问号按钮，指标口径由指标卡整体触发。保持既有紫色主题、布局、数值与业务行为不变。

## 文案分层

- 删除：重复入口介绍、页面已能自解释的功能描述、低价值静态快照说明。
- 保留可见：表单格式和配额约束、运行状态、错误及重试、权限引导、空态、样本截断、压力测试跳过原因、免责声明和必要的删除约束。
- 模块说明：图表、交易磨损、风险、归因及下一步等标题旁的内联 SVG 问号按钮。
- 指标说明：收益、夏普、回撤、胜率、VaR/ES、暴露度等整张指标卡；文字解释含义、区间、单位或缺失口径，不复制大段页面备注。
- 管理台采用同一规则，但不改变 8080 管理页，不为其增加移动端要求。

## 组件与交互

在共享 `LabUI` 增加轻量 help-tip，共享主题 CSS 使用现有 `--ink`、`--tint`、`--line`、`--lav` 和阴影变量，不引入新色相或依赖。

- 桌面：鼠标悬停显示，离开关闭；键盘聚焦同样显示。
- 触屏：点击切换，再次点击、点击外部或 Esc 关闭；不依赖 hover。
- 可访问性：原生 button 触发模块说明，`aria-describedby` 关联 `role=tooltip`；指标卡提供等价键盘触发方式。
- 边界：限制宽度并避免左右溢出；滚动或必要的上下文切换时关闭。
- 降级：reduced-motion 关闭过渡；JS 失败只损失补充说明，必要信息仍可见。
- 禁止 emoji 图标，使用内联 SVG；提示内容通过 `textContent` 写入，不拼接 HTML。

## 页面范围

覆盖 SaaS base、new、job、symbol、symbols、profile/dashboard/records、showcase、login、signals、strategy、feedback、factor_request 和 console。登录、反馈、因子申请等必要说明不能为了“精简”而删除。8080 既有管理页不在范围内。

## 实施边界

仅改 SaaS 模板、共享 `lab-ui.js`/`lab-theme.css`、对应测试和长期文档。不改 API、数据库、回测产物、引擎、权限和现有布局，不运行真实全量回测。优先复用现有卡片 `tip` 参数，再迁移到统一组件，避免保留两套新交互。
