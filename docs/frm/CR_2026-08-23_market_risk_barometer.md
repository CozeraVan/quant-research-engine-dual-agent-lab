# CR：大盘/板块风险风向标——截面聚合风险模块（QRE Market Risk Barometer）

- 日期：2026-08-23 ｜ 状态：✅ 用户已批准（"都做"：双加权、双板块口径、预警信号全做）
- 前置：CR_2026-08-21_frm_risk_module.md（R1–R4 已完成并接入回测/闸）、CR_2026-08-23_risk_derivatives_extension.md（R5–R7 已完成）
- 定位：把 FRM 个股风险指标**自下而上聚合 + 自上而下组合**成大盘/板块级风向标，作为市场系统性风险的日常监测。只读现有数据库，不改回测引擎行为。

## 1. 目标

新增日更产出 `market_risk_daily`：每个交易日输出全市场 + 各板块的风险指标与 0–100 归一化风险分数，GUI 增加「大盘风险」风向标展示，双指标超阈时亮红灯预警。

## 2. 方法（双路线交叉验证）

### 路线 A：自上而下（组合法）
- 全市场/板块分别按**等权**与**市值加权**合成组合日收益序列（市值权重用 tushare daily_basic 的 total_mv；若该表未入库，本 CR 含数据补全子任务，走 indicators_tushare 现有入库管线）。
- 对合成序列复用现有 risk 包：EWMA 波动率、VaR95/99、ES95/99、VaR 回测（Kupiec LR）——100% 复用 R1/R2，零新计算代码。

### 路线 B：自下而上（截面法，风向标核心）
对每日全市场个股横截面计算：
1. **截面波动率**：个股 EWMA σ 的中位数与 90 分位（风险总体水平与尾部厚度）。
2. **截面离散度**（cross-sectional dispersion）：当日个股收益的加权标准差（分化程度，历史风险预警指标）。
3. **平均两两相关系数**：滚动窗口（默认 60 交易日）个股收益两两相关的均值——等权与市值加权各一（相关性飙升 = 系统性风险积聚）。
4. **VaR 突破占比**：当日个股实际收益跌破各自 99% VaR 的比例（风险传染计数；个股 VaR 由 risk 包 EWMA 法逐股计算，向量化）。

### 风险分数与预警
- **风险分数**：四个截面指标 + 组合法 ES99 各自做 252 日滚动分位数（0–100），等权合成总分。
- **红灯预警**（双超阈）：平均相关系数的 20 日升幅 > 阈值 **且** VaR 突破占比 > 阈值 → `alert=red`；单超阈 → `alert=amber`。阈值集中 `risk/constants.py`，初值：相关系数 20 日升幅 > +0.10、突破占比 > 3%（99% VaR 期望突破率 1% 的 3 倍），初值需在首批真实数据上人工校准后调定。

## 3. 板块口径（双口径并行）

- **行业口径**：tushare stock_basic 行业分类（稳定、可解释）。
- **动态簇口径**：联动 cluster-ashare 的当日标签簇（自身特色，捕捉非行业聚集）。
- 两口径分别输出板块风险表；动态簇缺失/簇内股票 <5 只时该簇跳过。

## 4. 架构与集成

- 新模块 `src/quant_research_engine/risk/cross_section.py`：截面指标纯函数（输入：个股收益面板 + 权重 + 板块映射；输出：指标 dict）。零 DB、可向量化（numpy/pandas），参数集中 constants.py 并回显。
- 新模块 `src/quant_research_engine/risk/barometer.py`：组合法封装 + 分数归一化 + 预警判定 + 结果组装（纯函数）。
- 数据装配层 `src/quant_research_engine/risk/barometer_job.py`：唯一允许读 DB 的层（只读），从因子库/日线库取收益面板、市值、行业、簇映射，调用上述纯函数，落盘/入库结果。
- 存储：`market_risk_daily` 结果同时写 JSON 产物（outputs/market_risk/<date>.json，引擎与结果分空间存放的既有原则）与数据库表（cluster schema 或独立 market_risk schema，实施时与现有表归属对齐，QRE 对业务库只读的纪律下，写表走与 cluster 日更相同的既有写库通道）。
- 日更：插入日更链末端（17:30 cluster-ashare 之后、20:30 qre-refresh 之前，新增独立 systemd timer，如 18:30），Persistent=true，与现有五条链一致。
- GUI：dashboard/管理台新增「大盘风险」展示——总分仪表盘、四指标时间序列、板块热力表（行业 + 动态簇两 tab）、红灯/黄灯状态。复用现有 admin 卡片样式。
- 回填：上线后一次性回填近 252+60 交易日（满足相关系数窗口与分位数归一化的最小历史），分块执行。
